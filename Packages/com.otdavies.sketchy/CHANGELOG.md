# Changelog

## 0.1.0

- Initial Unity 6.3 / URP 17.3 package and local test project.
- Pencil Lit material, native Render Graph contours, continuous rendering.
- Reversible pipeline installer, style asset, paper UI shader and reference-city generator.
- Editor installation and rendering regression tests.
- Surface illumination in Unity and web, with dark unlit surfaces and optional Unity ambient fill.
- Finite outline segments reduce staircase spikes; drawing-rate gates and frame history removed from Unity and web.
- UV-free object-local/world triplanar material switch.
- Attenuated colored lighting on paper with fixed graphite color and adjustable stable point/spot falloff variation.
- Optional fitted pencil contours for hard/soft directional, point and spot cast-shadow boundaries.
- Local Unity testbeds excluded from Git; installation, samples and tests ship in the UPM package.
